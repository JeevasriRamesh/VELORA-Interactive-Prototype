VELORA – Interactive Fashion Shopping App Prototype

VELORA is a mobile-first fashion shopping application prototype designed to provide an elegant and user-friendly online shopping experience. It features a minimal white interface, rich burgundy accents, and stylish typography.

The project was designed using Figma and converted into an interactive web prototype so users can explore the application screens and navigation through a browser.

Features

- Welcome Screen:Introduction to the VELORA fashion shopping experience.
- User Authentication:Login and Sign Up screen navigation.
- Home Page:Displays new arrivals and trending fashion products.
- Product Details:View product images, prices, ratings, colours, and sizes.
- Wishlist:Explore and manage favourite products.
- Shopping Bag:View selected products and quantities.
- User Profile:View profile information and account options.
- Checkout:Review delivery address, payment methods, and order total.
- Order Confirmation:Confirmation screen after placing an order.
- Interactive Navigation:Navigate between screens using clickable buttons and icons.
