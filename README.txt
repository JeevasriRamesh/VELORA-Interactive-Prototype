VELORA INTERACTIVE PROTOTYPE

This is a static website made from the 11 Figma screen exports supplied by the designer.
It includes clickable navigation hotspots and a screen picker so visitors can explore the prototype.

LOCAL PREVIEW
1. Extract this folder.
2. Open index.html in Chrome or Edge.

HOST FOR FREE ON RENDER
1. Create a new GitHub repository named velora-interactive-prototype.
2. Upload all files and the assets folder from this project into the repository root.
3. In Render, choose New + -> Static Site.
4. Connect the GitHub repository.
5. Build command: leave blank.
6. Publish directory: .
7. Click Create Static Site.
8. Render will provide a public .onrender.com URL.

NOTES
- This is a clickable visual prototype, not a production shopping application.
- Login, payment, and order placement are demo navigation only; no real account, payment, or order is created.
- The screen picker can be used to jump directly to any of the 11 screens.
